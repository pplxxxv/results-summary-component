# Frontend Mentor - Results Summary Component

This is a solution to the **Results Summary Component** challenge from [Frontend Mentor](https://www.frontendmentor.io/).

## Overview

This project is a responsive results summary component built with HTML and CSS.

The component displays:

* The user's overall score
* Four different test categories
* Individual scores for each category
* A "Continue" button
* A responsive mobile layout

### Results

| Category | Score    |
| -------- | -------- |
| Reaction | 80 / 100 |
| Memory   | 92 / 100 |
| Verbal   | 61 / 100 |
| Visual   | 72 / 100 |
